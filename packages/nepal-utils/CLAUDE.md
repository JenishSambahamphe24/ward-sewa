# @ward-sewa/nepal-utils — Guidelines

Shared by the API and the web app. Read the root `CLAUDE.md` first; these rules add to it.

- **No runtime dependencies, and nothing Node- or browser-specific** (`fs`, `process`, `window`).
  The same code runs in Node and in Vite.
- **Public surface is `src/index.ts`.** `BsDateHelper`, `NumeralHelper`, `DivisionHelper` and the
  types in `types.ts`. Renaming or removing a method is a breaking change for every consumer; say so
  in the commit (`BREAKING:`).
- **Moments vs dates.** `today()` / `fromInstant()` take a moment and apply Nepal time.
  `fromAd()` / `toAd()` convert a calendar date exactly as given.
- **Invalid input throws** `RangeError` or `TypeError`; nothing rolls over silently.
- **Shared data is frozen.**
- **Data files record their source.** `src/data/bs-calendar.json` is generated by
  `pnpm build:calendar` and `divisions.json` by `pnpm build:divisions`; never edit either by
  hand.
- **Coverage stays at 100%** lines, branches and functions (`pnpm coverage`). If a branch can't be
  reached, restructure the code rather than adding a test-only path or lowering the threshold.
